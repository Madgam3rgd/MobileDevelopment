# Interactive Event Registration Application

This is an interactive mobile application created using React Native and TypeScript. The application allows a user to view information about an event and register by entering their name and email address.

## Features

- Displays event information
- Allows the user to enter a name
- Allows the user to enter an email address
- Register button
- Clear Form button
- Displays a registration confirmation after registering

## React Native Concepts Used

The application uses functional components, props, state with useState, TextInput, Pressable components, conditional rendering, and React Native styling.

## Running the Application

The application was developed and tested using the Android Emulator.

To run the application:

1. Start an Android Emulator.
2. Open the EventRegistration project.
3. Run:

npm run android
